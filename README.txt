ANGRY BIRDS 1.2.0 - RUST REBUILD
================================

Installed by AngryBirds_1.2.0_Setup.exe - a normal Windows setup wizard.
Nothing else is needed: the game, the uninstaller and the game data all
come inside that one file.

INSTALL
  Run AngryBirds_1.2.0_Setup.exe and click Next, Install, Finish.
  It needs no admin rights (installs for your user only).
  Silent install, for scripts:  AngryBirds_1.2.0_Setup.exe /S

WHAT IT DOES
  - installs to %LOCALAPPDATA%\AngryBirds1_2
  - puts the game and its data (1.2.0.ipa) there
  - creates a Desktop shortcut and a Start Menu folder
  - registers the game in Settings > Apps

PLAY
  Start it from the Desktop shortcut, the Start Menu, or the Finish page.
  Works completely offline. Progress, stars and highscores are saved in
  %APPDATA%\AngryBirds1_2_Rust.

UNINSTALL - NO TRACE LEFT
  Settings > Apps > Angry Birds 1.2.0 > Uninstall
  or the "Uninstall Angry Birds 1.2.0" shortcut in the Start Menu.
  Removes the game folder, your saves and settings, the shortcuts and the
  registry entries. Nothing outside those paths is touched.

IF WINDOWS BLOCKS IT
  'Windows protected your PC' -> More info -> Run anyway.
  Nothing happens on double-click -> right-click the exe > Properties >
  tick Unblock > OK.

CONTROLS
  drag the bird, release       aim and shoot
  Space / click                bird's special ability in flight
  arrows, WASD, left-drag      pan the camera
  mouse wheel                  zoom in / out (whole level fits on screen)
  [ / ]                        shrink / grow the interface
  R                            restart level
  Esc / P                      pause
  Home                         recentre the camera
  F11                          fullscreen
  M                            mute
